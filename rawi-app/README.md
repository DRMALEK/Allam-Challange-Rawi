Rawi Web Application!

Built Proudly Using Allam Larage Language Model. Url: https://arxiv.org/pdf/2407.15390, the dataset used is a collection of books for arabic poems and its explanation by the famous author Aref Hijjawi.

Used Technlogies:

    1. Typescript
    2. Node.Js
    3. Atlas MongoDB Vector database
    4. Clerk for authentication and authorizazion
    5. OpenAI Embeddings model
    6. Postgres Database for storing user infromation

How to run? 
    1. Make sure that you supplied all the environment keys as in the env.example
    2. Node v18 is installed
    3. Run npm install
    4. Postgresql is install
    5. Make sure that the schema is pushed to the postgresql 16.4
